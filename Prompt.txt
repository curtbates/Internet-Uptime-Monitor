Create an Internet Uptime Monitor application in Python. The goal is to monitor an ISP by periodically querying DNS servers and tracking public IP changes. All code must run on both Windows and Linux.

---

PROJECT STRUCTURE

    main.py                  — entry point (terminal)
    main.pyw                 — entry point (no console window; errors via messagebox)
    version.py               — single source of truth: __version__ = "20260912a"
    utils.py                 — shared helpers (calculate_score)
    config_manager.py        — load/save config.json
    database.py              — SQLite helpers
    dns_checker.py           — DNS query logic
    ip_tracker.py            — public IP / ISP lookup (split: fast check vs. ISP lookup)
    gui/__init__.py          — empty
    gui/main_window.py       — main window; composes _PollMixin and _TrayMixin
    gui/_poll_mixin.py       — polling loop: worker thread, queue drain, result handler
    gui/_tray_mixin.py       — system tray: icon, hide/restore, menu
    gui/graph_panel.py       — matplotlib graph widget
    gui/setup_dialog.py      — modal setup dialog
    tests/conftest.py        — pytest fixture: redirects DB to temp directory
    tests/test_utils.py      — calculate_score() tests
    tests/test_database.py   — database CRUD and purge tests
    tests/test_config.py     — config load/save/back-fill tests
    tests/test_ip_tracker.py — _is_valid_ipv4() tests
    tests/test_graph_panel.py — bucket helper tests

main.pyw is identical to main.py in behaviour. On Windows, pythonw (invoked
automatically for .pyw files) runs without a console window. If a required
package is missing it shows a tkinter messagebox instead of a console traceback.

SCORE FORMULA (utils.py)

Define calculate_score(ok_count, total, response_times_ms) -> float in utils.py.
Import and call it from both _poll_mixin.py (live poll handler) and graph_panel.py
(Summary Score view). Never duplicate the formula.

    success_rate = ok_count / total if total else 0.0
    rt_score     = max(0.0, min(1.0, 1.0 - (avg_rt - 20) / 480))
                   (20 ms → 1.0,  500 ms → 0.0; 0.0 when no successful responses)
    score        = min(100.0, (success_rate * 0.5 + rt_score * 0.5) * 100)

CONFIG (config.json, stored next to the scripts)

Defaults if file is missing or corrupt:
    schema_version: 1
    polling_interval_seconds: 60
    log_dns: true
    log_only_incomplete_dns: true
    log_score: true
    log_score_below_80_only: false
    save_event_log: false
    log_ip_success: true
    log_isp_changes: true
    dns_providers: [
        {"name": "Google",     "server": "8.8.8.8"},
        {"name": "Cloudflare", "server": "1.1.1.1"},
        {"name": "OpenDNS",    "server": "208.67.222.222"},
        {"name": "Quad9",      "server": "9.9.9.9"},
        {"name": "Comodo",     "server": "8.26.56.26"}
    ]
    domains: ["google.com", "amazon.com", "cloudflare.com", "microsoft.com", "github.com"]

load_config() must back-fill any keys missing from an older config file using
DEFAULT_CONFIG.setdefault() so upgrades never require manual file edits.

log_dns (bool, default true):
    When true, DNS poll summary lines are written to the Event Log.
    When false, all DNS poll messages are suppressed regardless of
    log_only_incomplete_dns.

log_only_incomplete_dns (bool, default true):
    Effective only when log_dns is true. When true, the per-poll DNS summary line
    is written only when at least one query failed. When false, written every poll.

log_score (bool, default true):
    When true, the computed summary score (0–100) is written to the Event Log after
    each poll, colour-coded: "ok" tag (green) when score >= 80, "fail" tag (red)
    when score < 50, no tag otherwise.

log_score_below_80_only (bool, default false):
    Effective only when log_score is true. When true, score messages are suppressed
    unless the score is below 80.

save_event_log (bool, default false):
    When true, every message passed to _log_event() is appended to event.log in
    APP_DIR. When false (or when the user saves the dialog with this false), delete
    event.log if it exists.

log_ip_success (bool, default true):
    When true, IP address change and detection messages are written to the Event Log.
    When false, only the IP check failure message is logged. Database inserts and
    _last_ip / _last_ipv6 state updates are unaffected.

log_isp_changes (bool, default true):
    When true and both the IP and ISP changed in the same poll, combine them into
    one log entry: "Public IP changed to X  (ISP: Old → New)".
    When both log_ip_success and log_isp_changes are true and the ISP changed,
    use the combined message instead of two separate lines.
    When only log_isp_changes is true (log_ip_success false), write only the ISP
    change message.
    When only log_ip_success is true (log_isp_changes false), write only the IP
    change message with the new ISP in parentheses.
    _last_isp is always updated regardless of this flag.

DATABASE

Store the database in a platform-specific application data directory:
    Windows   %APPDATA%\InternetUptimeMonitor\uptime_monitor.db
    Linux     ~/.InternetUptimeMonitor/uptime_monitor.db

Expose the directory as the module-level constant APP_DIR so other modules can
import it to locate sibling files such as event.log.

Table dns_results:
    id               INTEGER PRIMARY KEY AUTOINCREMENT
    timestamp        REAL NOT NULL          -- Unix epoch float
    dns_provider     TEXT NOT NULL
    domain           TEXT NOT NULL
    response_time_ms REAL                   -- NULL on failure
    success          INTEGER NOT NULL       -- 1 or 0

Table ip_log:
    id          INTEGER PRIMARY KEY AUTOINCREMENT
    timestamp   REAL NOT NULL
    public_ip   TEXT NOT NULL              -- dotted-decimal IPv4
    isp_name    TEXT
    org         TEXT                       -- raw "AS12345 ISP Name" string
    public_ipv6 TEXT                       -- IPv6 address; NULL when not available

Table ip_failures:
    id        INTEGER PRIMARY KEY AUTOINCREMENT
    timestamp REAL NOT NULL               -- when the failure was first detected

One ip_failures row is written each time a working IP check transitions to
failure (i.e. the first poll that returns None after a successful poll).
Back-to-back failures within the same outage do not add additional rows.

Index timestamp on all three tables. Purge records older than 10 days; run once
at startup and re-schedule every 24 hours.

Schema migration: initialize_db() must handle databases created before
public_ipv6 was added. After the CREATE TABLE IF NOT EXISTS block, check
PRAGMA table_info(ip_log); if public_ipv6 is absent, run:
    ALTER TABLE ip_log ADD COLUMN public_ipv6 TEXT

DNS CHECKER (dns_checker.py)

Function: check_dns(server_ip, domain, timeout=5.0) -> tuple[bool, float | None]

Use dnspython with configure=False (ignore system resolver). Set both lifetime
and timeout to the timeout value to disable implicit retries. Query an A record.
Measure elapsed time with time.perf_counter(). Catch specific expected exceptions
(dns.exception.Timeout, NXDOMAIN, NoAnswer, NoNameservers, OSError) and return
(False, None). A bare except Exception is acceptable as a final catch-all but
should also return (False, None). Return (True, elapsed_ms) on success.

IP TRACKER (ip_tracker.py)

IMPORTANT: Split the IP check and ISP lookup into two separate functions. Free-tier
ISP services (ipinfo.io, ipapi.co) have rate limits that a 60-second polling
interval will exceed (~1,440 req/day), causing HTTP 429 responses and "Unknown"
ISP. The fix is to call the cheap IP-only services every poll and the ISP services
only when the IP actually changes.

IP validation
-------------
_is_valid_ipv4(addr: str) -> bool
Compile _IPV4_RE = re.compile(r"^\d{1,3}(\.\d{1,3}){3}$") at module level.
Use it to reject HTML error pages or other non-IP strings before storing them.

Fast IP fetch (called every poll)
----------------------------------
Function: get_public_ip(timeout=10) -> str | None

Try these services in order via _ipv4_session:
  1. https://api.ipify.org?format=json  — JSON; "ip" field
  2. https://checkip.amazonaws.com      — plain text; entire body is the IP

For each, attempt resp.json() first; catch ValueError and use resp.text.strip().
Validate with _is_valid_ipv4() before returning. Return None if all fail.

ISP lookup (called only when IP changes)
-----------------------------------------
Function: get_isp_for_ip(ip: str, timeout=10) -> tuple[str, str]
Returns (isp_name, org_raw). Falls back to ("Unknown", "") if all services fail.

Try these services in order via _ipv4_session:
  1. http://ip-api.com/json/{ip}?fields=status,isp,org,query
     — JSON; check data["status"] == "success"; use data["isp"] or data["org"]
     — Note: HTTP only on the free tier
  2. https://ipinfo.io/json     — JSON; "org" field contains "AS1234 ISP Name"
  3. https://ipapi.co/json/     — JSON; "org" or "isp" field

For ipinfo.io / ipapi.co style responses:
    org = data.get("org", "") or data.get("isp", "") or ""
    if org.startswith("AS"):
        isp = org.split(" ", 1)[1] if " " in org else org
    else:
        isp = org

IPv4 dual-stack prevention
---------------------------
On dual-stack hosts, requests may route to ipinfo.io over IPv6, causing the
service to echo back the IPv6 address instead of the IPv4 address.
Prevent this with a custom HTTPAdapter subclass (_ForceIPv4Adapter) that
temporarily sets urllib3.util.connection.allowed_gai_family to return
socket.AF_INET. Mount it on a module-level Session (_ipv4_session) for both
"https://" and "http://". Use _ipv4_session.get() for all IP/ISP service calls.

IPv6 fetch
----------
Function: _fetch_ipv6(timeout=5) -> str | None
Use plain requests.get() (not _ipv4_session) to hit:
    https://api6.ipify.org?format=json
This endpoint has only AAAA DNS records so only IPv6 hosts can reach it.
Return the "ip" field, or None on any exception.

Compatibility shim
------------------
Function: get_public_ip_info(timeout=10) -> dict | None
Returns {"ip": str, "ipv6": str|None, "isp": str, "org": str} or None.
Calls get_public_ip(), then get_isp_for_ip(), then _fetch_ipv6().
Used only on the first poll or when a full combined result is needed.

POLL MIXIN (gui/_poll_mixin.py)

Mixin class _PollMixin. Methods access self attributes set by MainWindow.__init__.

In _poll_worker() (runs in daemon thread — no tkinter access):
  1. Run check_dns() for each provider × domain combination.
  2. Call get_public_ip() — fast, no rate-limit concern, every poll.
  3. If ip != self._last_ip: call get_isp_for_ip(ip) and _fetch_ipv6() to
     get fresh ISP data and IPv6. Build ip_info dict with all four fields.
  4. Else (IP unchanged): reuse self._last_isp; still call _fetch_ipv6() to
     detect IPv6 changes. Set ip_info["isp"] = self._last_isp or "Unknown".
  5. If get_public_ip() returned None: set ip_info = None.
  6. queue.put(("done", ts, dns_results, ip_info))

In _handle() (main thread):
  - Insert all DNS results to DB.
  - IP/ISP/IPv6 change detection and logging (see CONFIG section above for
    combined log message logic).
  - Compute score with calculate_score() from utils.py; store as _last_score.
  - Log DNS poll summary and score per config flags.
  - Update status bar labels, refresh graph, update tray, schedule next poll.

  - queue.Queue between worker and main thread; drain every 200 ms.
  - Track _last_ip, _last_ipv6, _last_isp, _last_score in __init__.

  transition whose timestamp <= the DNS row's timestamp.

  Write "  (no records)" when a section is empty.

GRAPH PANEL (gui/graph_panel.py)

Embed a matplotlib Figure (9×4 inches, 100 dpi). Use TkAgg backend. Use
tight_layout() and autofmt_xdate(rotation=30) after each draw.

CONTROLS ROW:
  "View:" + radio buttons: By Provider | By Domain | Summary Score
  Vertical separator
  "Range:" + readonly Combobox: Last 1h | Last 6h | Last 24h | Last 7d
  "Refresh" button
  Vertical separator
  "ISP:" + readonly Combobox (from get_distinct_isps() + "All ISPs")

TIME RANGES AND BUCKET SIZES:
  Last 1h  →  60 s buckets
  Last 6h  → 300 s buckets
  Last 24h → 900 s buckets
  Last 7d  → 3600 s buckets

Bucket formula: int(timestamp / bucket_s) * bucket_s

ISP FILTER:
  When an ISP is selected, use bisect to find the active ISP at each DNS
  result's timestamp in O(log N). Build two parallel lists from ip_log:
  timestamps and isp_names. Use bisect.bisect_right(timestamps, r["timestamp"]) - 1
  to find the index, then check isp_names[idx].

SHARED PLOT METHOD:
  _plot_by_group(results, bucket_s, key_fn, title) handles both "By Provider"
  and "By Domain" views. key_fn is lambda r: r["dns_provider"] or
  lambda r: r["domain"]. Do not duplicate the plotting loop.

BY PROVIDER VIEW
  Call _plot_by_group with key_fn=lambda r: r["dns_provider"].
  Title: "DNS Response Time by Provider". Y-axis: "Avg Response Time (ms)".

BY DOMAIN VIEW
  Call _plot_by_group with key_fn=lambda r: r["domain"].
  Title: "DNS Response Time by Domain". Y-axis: "Avg Response Time (ms)".

SUMMARY SCORE VIEW
  Use calculate_score() from utils.py for each bucket.
  Single steelblue line with fill_between (alpha=0.25).
  Reference lines: orange dashed at 80, red dashed at 50.
  Title: "Summary Score  (50 % success rate + 50 % response time)"
  Y-axis: "Score (0 – 100)", ylim (0, 105).
